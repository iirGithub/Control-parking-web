# Control parking · Demostración

Panel público de demostración para Peugeot 408 y SEAT Ibiza.

Los dos vehículos muestran «Sin información». No se infiere su ubicación. No contiene matrículas, correos, credenciales ni históricos privados. No consulta Telpark, Gmail ni repositorios privados.

Sitio estático sin dependencias, JavaScript ni solicitudes externas. Publicación mediante GitHub Pages desde `main` y `/ (root)`.

URL: https://iirgithub.github.io/Control-parking-web/
